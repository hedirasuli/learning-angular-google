# Learning Angular with Google Integration

This repository is dedicated to my journey of learning **Angular** and integrating various **Google Services**. It contains experiments, core concepts, and practical implementations of modern web development patterns.

## 🚀 Project Goals
* Mastering **Angular CLI** and project structure.
* Implementing **Component-based architecture**.
* Integrating Google Services (Maps, Firebase, or Auth).
* Understanding **RxJS** and Reactive Programming.
* Learning **Dependency Injection** and Services.

## 🛠️ Tech Stack
* **Framework**: [Angular](https://angular.io/) (v17+)
* **Language**: TypeScript
* **Styling**: SCSS / CSS3
* **Tools**: Angular Material, RxJS
* **Services**: Google Maps API / Firebase (Optional - based on progress)

## 📦 Installation & Setup

1. **Clone the repository**:
   ```bash
   git clone [https://github.com/hedirasuli/learning-angular-google.git](https://github.com/hedirasuli/learning-angular-google.git)
    ```
   ### 2. Install Dependencies:
   Make sure you have Node.js installed, then run:
    ```bash
    npm install -g @angular/cli
    ```
    ### 3. Install Angular CLI (if not already installed):
   ```bash
   npm install -g @angular/cli
   ```
   ### 4. Run the Development Server:
   ```bash
   ng serve
   ```
   Navigate to http://localhost:4200/. The app will automatically reload if you change
   any of the source files.
